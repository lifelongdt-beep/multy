# 퇴근 에코 (가제) — 한 장 기획서

**한 줄 소개**: 죽은 과거의 나와 함께 싸우며, 한 판마다 군단이 커지는 2분짜리 한 손 서바이버.

## 1. 제약 조건 (확정)
| 항목 | 내용 |
|---|---|
| 개발 인원 | 1인 (웹 개발자) |
| 작업 시간 | 하루 3시간 (주 약 21h, 12주 약 250h) |
| 플랫폼 | 웹(PWA) → 모바일 앱(Capacitor) |
| 수익 | 인앱결제 중심, 광고 없음 (구조만 열어 둠) |
| 타깃 | 10대, 직장인 |
| 지역 | 한국 우선 |
| 그래픽 | AI 생성 |
| 마케팅 | 직접 숏폼 제작 |
| 첫 월드 | **학교** |

## 2. 컨셉
- 핵심: **에코 서바이버** (이동만 조작, 공격 자동) + **친구 에코/일일 랭킹** + **풍자 테마**
- 월드 = 시즌 콘텐츠 단위. 로직은 그대로, 에셋만 교체.
  1. **학교** (첫 월드): 숙제, 시험지, 학원 알림에서 탈출. 보스는 기말고사.
  2. **야근 사무실**: 이메일, 회의, 상사에서 퇴근 출구로.
  3. **우주**: 지구 탈출 엔딩, 후반 콘텐츠.

## 3. 핵심 루프 (한 판 120초)
1. 드래그 한 손으로 이동, 공격은 자동.
2. 처치 시 경험치 구슬 → 레벨업 3택1 강화.
3. 90초에 보스 등장. 보스 격파 / 120초 생존 / 사망으로 판 종료.
4. **판 종료 시 이동 경로 + 강화 선택 기록이 "에코"로 저장.**
5. 다음 판부터 과거의 에코들이 같은 경로·같은 강화 상태로 함께 싸운다.
6. 오래 살아남은 판의 에코일수록 오래 함께 싸운다 → **죽음/생존이 다음 판의 자산**.

**첫 30초 후크**: 1판은 평범 → 2판 시작 순간 "아까의 내가 나타났다" → 3판부터 화면이 꽉 찬다.

## 4. 성장 구조
- 판 내: 레벨업 3택1 (연사, 다중발사, 공격력, 이동, 자석, 관통)
- 판 간: 에코 수 증가 (눈에 보이는 폭발). 최대 10명, 오래된 에코부터 교체.
- 메타 (이후): 영구 업그레이드, 월드 해금, 에코 역할(공격/방어막/자석)
- 폭발 설계: 에코 수에 비례한 화력 누적 + 이펙트. 상한과 곡선은 밸런싱에서 조정.

## 5. 수익 모델 (인앱결제, 광고 없음)
| 상품 | 내용 | 원칙 |
|---|---|---|
| 에코 스킨 | 교복 유령, 사원증 유령, 우주비행사 등 | 핵심 매출, 성능 영향 없음 |
| 시즌패스 | 월드별 한정 스킨/이펙트 | 반복 매출 |
| 편의 상품 | 에코 슬롯 확장, 이어하기 | 성능 우위가 되지 않도록 상한 |
| 랭킹 참가권 | 일일 무료 1회 + 추가 | 과금 압박 낮게 |
- 원칙: "돈 쓰면 이긴다"가 아니라 "돈 쓰면 멋지다".
- 10대 결제: 연령별 한도와 스토어 정책 사전 확인 필요.
- 광고 없이 결제만으로는 전환율이 낮으므로 유저 수 확보(숏폼)가 관건.

## 6. 기술 구성
- TypeScript(또는 순수 JS) + Canvas/Phaser/PixiJS, 웹 우선
- **결정론적 시뮬레이션**: 고정 60Hz 타임스텝 + 시드 난수. 에코는 입력 기록만 저장(경량).
- PWA 먼저 → Capacitor로 스토어 래핑(인앱결제 플러그인 필요)
- 서버리스(Supabase/Firebase): 로그인, 일일 시드 랭킹, 친구 에코 공유
- 한국 유통: 구글플레이/앱스토어 외 국내 미니앱 플랫폼은 출시 전 최신 조건 확인(미검증)

## 7. 12주 일정 (하루 3시간 기준)
| 주차 | 목표 |
|---|---|
| 1~2 | **프로토타입**: 이동, 자동공격, 적 스폰, 결정론 시뮬레이션, **에코 재생**. 에코 3~5명이 쌓였을 때 재미있는지 판정 |
| 3~4 | 레벨업/보스/판 간 성장 정비, 밸런싱 1차 |
| 5~6 | 학교 월드 완성, AI 아트 적용, 사운드/이펙트("폭발감") |
| 7~8 | 메타 성장, 계정, 일일 시드 랭킹, 친구 에코 |
| 9~10 | 결제 연동, 월드 2(사무실), 튜토리얼, 분석 이벤트 |
| 11 | 비공개 테스트(10~20명), D1/D7 리텐션 확인 |
| 12 | 숏폼 10개 이상 비축 후 출시 |
- 주 21h 기준 여유가 크지 않으므로, 월드 2 이후와 친구 에코는 출시 후 업데이트로 미룰 수 있다.
- 출시 전 숏폼 제작 시간을 주당 3~4h 확보한다.

## 8. 숏폼 마케팅
- 후크: "1판 vs 10판 후", "내 에코 군단", "죽을수록 강해지는 게임"
- 풍자 밈: 학교/직장 공감 소재 (틱톡, 쇼츠, 릴스)
- 개발 일지: 솔로 개발 과정 공개
- 결과 화면 공유 카드 자동 생성 (Wordle식)

## 9. 위험 요소
1. 에코의 재미 미검증 → 프로토타입에서 최우선 검증
2. 마케팅 의존 (광고 없음)
3. 곱연산 폭주에 따른 밸런스 붕괴
4. 10대 대상 결제/스토어 정책
5. AI 에셋 일관성 (스타일 가이드 선고정)
