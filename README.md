# Echo Rush

자동공격 서바이벌 + **에코(과거의 나)** 모바일 게임입니다.
한 판이 끝나면 그 판의 내 움직임과 강화 기록이 **유령(에코)** 이 되어 다음 판에서 함께 싸웁니다. 어제의 내가 오늘의 나를 돕는 게임입니다.

- 목표: 모바일 앱 출시 / 수익화 / AI 활용 아트
- 현재: 웹 프로토타입(순수 JS, 외부 라이브러리 없음). 로드맵 0~3단계 완료.

## 실행

```bash
npm run serve   # http://localhost:8080 (폰에서는 같은 네트워크의 PC 주소로 접속)
npm test        # 테스트 (node:test, 별도 설치 없음)
```

조작: 화면 드래그(키보드는 방향키/WASD). 공격은 자동입니다.

## 구조

| 파일 | 역할 |
|---|---|
| `src/worlds.js` | 월드 데이터(순수 데이터): 배경, 적, 웨이브, 포위 이벤트, 도우미, 보스·패턴, 고유 규칙. **새 월드는 여기에 추가** |
| `src/sim.js` | 결정론적 시뮬레이션 코어 (DOM 없음, 60Hz 고정 틱, 시드 난수). 밸런스는 파일 위쪽 `TUNING` |
| `src/meta.js` | 메타 진행 (DOM 없음): 학점, 상점, 캐릭터, 도전 과제, 일일 미션, 저장/백업 코드, 에코 풀 규칙 |
| `src/ui.js` | 메타 화면: 월드 선택 / 상점 / 캐릭터 / 과제·미션 / 백업 |
| `src/main.js` | 입력, 렌더, 에코 저장, 연출(흔들림·진동·배너) |
| `src/audio.js` | WebAudio 합성 효과음 (외부 에셋 없음) |
| `test/*.test.js` | `sim`(규칙) · `worlds`(월드·보스·도우미·가치 원칙) · `meta`(진행·저장) 테스트 |

시뮬레이션 코어에는 `Math.random`이 없어서 같은 시드·입력이면 결과가 같습니다. 그래서 봇으로 밸런스를 재고 테스트로 재현할 수 있습니다.

## 게임 규칙 요약

**한 판**: 약 2분. 방해 요소를 물리치며 구슬로 성장하고(레벨업 3택 1, 업그레이드 12종·시너지 4종), 월드의 **큰 도전(보스)** 을 극복하면 클리어입니다.

**에코**
- 판이 끝나면 그 판의 나(이동 경로+강화 기록)가 에코로 저장되어 다음 판에 함께 싸웁니다. 맞아도 사라지지 않고, **기록이 끝나는 시점**(그 판에서 내가 쓰러진 시간)에 사라집니다.
- 정원 10명. 넘치면 **가장 일찍 쓰러진 에코부터** 내보냅니다.
- **월드를 옮기면 에코가 모두 초기화**됩니다(월드 화면에서 한 번 더 눌러 확인).
- 에코가 있어야 보스를 깰 수 있습니다(아래 "큰 도전").

**월드**

| 월드 | 학점 배율 | 방해 요소 | 도우미 | 큰 도전(보스) · 등장 시각(초) | 필요 에코 | 고유 규칙 |
|---|---|---|---|---|---|---|
| 🏫 학교 | x1.0 | 미루기·걱정·딴생각·지각·졸음·게으름 | 담임 선생님 | 시험 불안 · 90 | 7 | 없음 |
| 📖 학원 | x1.3 | 조급함·불안·잡념·미루고 싶은 마음·포기 충동 | 학원 선생님 | 슬럼프 · 85/125 | 8 | 경험치 +30%, 원거리 적 多 |
| 🏢 회사 | x1.6 | 스트레스·압박감·산만함·고장난 프린터·끝없는 걱정 | 멘토 선배 | 번아웃 · 80/115/150 | 9 | 방해를 잡으면 가끔 ☕(체력 +12) |
| 🚇 지하철 | x2.0 | 졸음·무거운 가방·시끄러운 방송·스마트폰 알림·쌓인 피로 | 친절한 역무원 | 급행열차 · 75/110/145/180 | 9 | 열차 습격(경고 줄 후 질주, 치이면 최대 체력 40%) |

- 해금: 앞 월드의 보스를 한 번 극복하면 다음 월드가 열립니다.

**큰 도전(보스)**
- 월드가 높을수록 더 자주 나옵니다(1·2·3·4번). 하나를 극복해야 다음이 나오고, 극복할 때마다 체력이 25% 회복됩니다.
- 보스 체력은 `(기준 화력: 나 + 에코 needEchoes명) x 목표 시간`으로 정해지고 **에코의 화력은 체력에 반영되지 않습니다.** 에코가 필요 수보다 적으면 전투가 길어져 버티기 어렵고, 필요 수만큼 있으면 겨우, 더 많으면 여유 있게 잡습니다. 내 화력이 기준보다 세면 보스는 그 √배만 단단해집니다.
- 보스전 중에는 받는 피해 +25%(최대 체력이 높을수록 추가), 체력 재생 40%. 32초가 넘으면 보스가 격앙되고 받는 피해가 초당 +15%씩(최대 6배) 늘어납니다.

**도우미(도움 요청하기)**: 45초에 선생님·선배·역무원이 찾아옵니다. 곁의 빛나는 원에 2.5초 머물면 조언 카드 3장 중 하나(체력 절반 회복 / 공격력 / 발사 속도 / 에코 응원)를 받습니다. 못 가도 벌은 없습니다.

**메타 진행**: 학점(재화) → 상점 8종(각 Lv5, 체력·공격력·속도·구슬 범위·경험치·재생·에코 단련·학점 획득), 캐릭터 4종(학생·운동부·전교 1등·보건 도우미), 도전 과제 17개, 일일 미션(날짜로 결정, 3개). 기기(localStorage)에 자동 저장되고, 기기 이전용 **백업 코드**(학점·강화·캐릭터·과제, 에코 제외)를 내보내고 불러올 수 있습니다.

## 디자인 원칙: 재미와 올바른 가치

이 원칙은 `test/worlds.test.js`의 자동 검사로도 지켜집니다.

1. **사람은 적이 아니다.** 선생님·선배·역무원·승객은 적(중간 보스 포함)으로 나오지 않습니다.
2. **숙제·시험·업무는 나쁜 것이 아니다.** 괴롭히는 것은 "숙제"가 아니라 **미루는 마음**, "시험"이 아니라 **시험 불안**입니다.
3. 적은 마음속·환경의 **방해 요소**(미루기, 걱정, 졸음, 산만함, 피로, 알림)입니다.
4. 보스는 이기는 대상이 아니라 **극복**하는 도전입니다(시험 불안, 슬럼프, 번아웃, 급행열차).
5. **도움을 청하는 것은 좋은 일**입니다(도우미, 도움 요청하기 과제·미션).
6. **실패해도 괜찮다**: 결과 화면에 따뜻한 한마디, 쓰러진 나는 에코가 되어 다음 판을 돕습니다.

| 상점·캐릭터·학점 보상 | `src/meta.js` |

## 검증과 한계

- 테스트 91개(규칙, 월드, 가치 원칙, 진행·저장, 성능). 시뮬레이션은 월드당 틱당 1ms 미만입니다.
- **밸런스는 봇 시뮬레이션으로 맞췄습니다.** 학교(필요 에코 7명)와 학원·회사는 에코 수에 따른 클리어율이 의도대로 나왔고, **지하철은 봇이 보스 4번을 버티지 못해 검증하지 못했습니다.** 실제 플레이로 조정이 필요합니다.
- 폰 실기기에서의 터치·소리·진동·성능은 확인하지 못했습니다(아이폰은 웹 진동이 지원되지 않습니다).
- 저장은 기기 안뿐이라 사이트 데이터를 지우면 사라집니다. 에코는 백업 코드에 포함되지 않습니다.
