# Echo Rush

자동공격 서바이벌 + **에코(과거의 나)** 모바일 게임. 한 판(120초)이 끝나면 그 판의 내 이동·강화 기록이 귀여운 동료(에코)가 되어 다음 판에서 함께 싸웁니다.

목표: 모바일 앱 출시 / 수익화 / AI 활용 아트.

## 실행

```bash
npm run serve   # http://localhost:8080 (폰에서는 같은 네트워크의 PC IP로 접속)
npm test        # 시뮬레이션 테스트
```

### 1단계 변경점

- **방해 요소 + 웨이브 표**: 미루기·걱정·딴생각에 지각(돌진)·졸음(원거리)·게으름(분열)을 추가. 시간대별 가중치 웨이브와 포위 이벤트(30/62/100초). (3·4단계에서 '사람을 적으로 만들지 않는다'는 원칙에 맞춰 재구성 — 아래 참고)
- **업그레이드 12종 (최대 Lv5) + 시너지 4종**: 치명타·종소리(충격파)·형광펜(공전)·급식(재생)·에코 응원·보건실(즉시 회복) 추가. 조합 시 시너지 발동.
- **에코 규칙**: 에코는 맞아도 사라지지 않고 기록이 끝나는 시점에만 사라짐 (오래 버틴 에코일수록 오래 도움) / 오래된 에코일수록 공격력 -5%씩 / 에코가 많을수록 적·보스 체력 증가 / 정원(10명) 초과 시 가장 일찍 쓰러진 에코부터 퇴장(오래 버틴 에코만 남음)(난이도 연동) / 에코 응원 업그레이드로 강화.
- **보스 "시험 불안" 3페이즈**: 탄막 → 졸개 소환 → 조준 3연발 + 가속. 90초 등장, 120초까지 못 잡으면 최대 60초 연장전(보스전 중 졸개 스폰 절반).
- **연출·사운드**: 합성 효과음 12종, 화면 흔들림, 진동, 데미지 숫자(치명타 강조), 배너, 음소거 버튼.

> 밸런스 수치는 봇 시뮬레이션으로만 확인했습니다. 실제 사람 플레이테스트로 `TUNING` 값을 다듬어야 합니다.

### 2단계 변경점

- **학점(재화)**: 한 판이 끝나면 처치·생존 시간·레벨·보스 격파에 따라 지급. 상점의 "장학금"으로 증가.
- **영구 강화(상점) 8종, 각 Lv5**: 체력 / 공격력 / 이동속도 / 구슬 범위 / 경험치 / 체력 재생 / 에코 단련 / 학점 획득. 레벨이 오를수록 비용 x1.7.
- **캐릭터 4종**: 학생(기본) · 운동부 · 독서부 · 보건 도우미. 학점으로 해금. 각자 능력치와 시작 아이템이 다르고, 시작 아이템은 에코에게도 전달됨.
- **도전 과제 12개 + 일일 미션 3개**: 달성 시 학점 보상. 일일 미션은 날짜로 결정(같은 날 항상 같은 구성).
- **저장**: 기기(localStorage)에 자동 저장. 기기 이전용 **백업 코드** 내보내기/불러오기. 서버 저장은 계정 시스템이 필요해 4단계로 미룸.

### 에코는 월드마다 새로 시작

- 에코는 쌓은 월드에서만 함께합니다. **다른 월드로 옮기면 에코가 모두 사라지고** 0명에서 다시 쌓습니다.
- 월드 선택 화면에서 에코가 사라지는 경우 한 번 더 눌러 확인하게 해 실수로 잃지 않도록 했습니다.
- 난이도는 "에코 0명에서 시작"을 기준으로 월드마다 다시 맞췄습니다. (봇 기준: 첫 판은 어렵고, 에코와 도움이 쌓이면 클리어가 늘어나는 곡선)

### 월드 12개 · 회차 · 월드별 매점 장비

- **월드 12개**: 학교 → 학원 → 회사 → 지하철 → 집 → 헬스장 → 도서관 → 바닷가 → 공항 → 병원 → 산 → 꿈의 무대. 바로 앞 월드의 큰 도전을 극복하면 다음 월드가 열립니다. 5번째 월드부터 큰 도전은 3~4번.
- **새 규칙**: `sight`(조준 거리, 밤·안개), `wind`(좌우 바람), `dropEmoji`(회복 아이템 모양), `trains.emoji/text`(카트·조명처럼 열차 규칙 재사용).
- **적이 강해지는 만큼 장비가 필요**: 단계 = 월드 순서(0~11) + 12 x 회차. 단계가 1 오를 때마다 적 체력(보스 포함) x1.06³, 적 피해 x1.05³.
- **월드별 매점 장비**: 월드마다 ⚔ 공격 장비(레벨당 **나와 에코 모두** 공격력 x1.06) + 🛡 방어 장비(레벨당 받는 피해 ÷1.05). 그 월드에 도착하면 매점에 입고됩니다. 단계당 ⚔3 + 🛡3레벨이 **권장 장비**이고, 권장만큼 사면 적이 강해진 만큼 정확히 상쇄됩니다(월드 화면과 매점에 "권장 ⚔N 🛡N · 내 장비"가 표시되고, 모자라면 시작할 때·결과 화면에서 알려 줍니다). 열차·카트·조명처럼 최대 체력 비율로 깎는 피해는 장비로 줄지 않습니다.
- **회차**: 12번째 월드를 극복하면 다음 회차로 학교부터 다시 시작합니다. 회차마다 적 체력 x1.1 추가·이동 +5%·스폰 +8%, 장비 최대 레벨 +5 (1회차 5 → 2회차 10 → …). 2회차부터는 모든 월드의 매점이 열려 있습니다. 1회차 마지막 권장 장비는 살 수 있는 최대치의 55%, 회차가 오를수록 비율이 높아져(2회차 74%, 3회차 83% …) 점점 빡빡해집니다.
- **끝없는 회차 경제**: 장비 가격 = 90 x 1.06^(산 ⚔ 레벨 합) (🛡은 1.05^), 학점 = 기본 보상 x 그 단계의 적 체력 배율. 적이 강해지는 만큼 수입도, 필요한 장비 값도 같은 비율로 커져서 몇 회차가 되어도 '다음 월드까지 장비값 ≈ 1~2판 수입'이 유지됩니다. 장비 최대 레벨은 회차마다 +5. 학점이 커지면 1.2만·3억·4.5조처럼 짧게 표시합니다.
- **봇 측정** (에코 10명, 월드당 4판): 바닷가 장비 없음 0/4 · 절반 1/4 · 권장 4/4, 꿈의 무대 없음 0/4 · 절반 0/4 · 권장 4/4, 2회차 학교 없음 0/4 · 절반 1/4 · 권장 4/4. 학원·집은 장비 없이도 일부 클리어(초반은 완만).
- 튜닝 값: `src/worlds.js`의 `GEAR`(공격/방어 배율, 단계당 필요 레벨, 회차 배율, 가격).

### 튜토리얼 · 일시정지 · 에코 백업

- **튜토리얼**: 처음 실행하면 "과거의 나 10명과 함께 한 판"을 먼저 체험합니다(건너뛰기 가능, 메뉴의 📘 튜토리얼로 다시 하기). 연습용 에코 10명은 시드로 만든 경로와 성장 기록이며, 안내 문구가 시간에 맞춰 나옵니다. 튜토리얼 판은 **내 에코·학점·과제 기록에 반영되지 않고**, 끝나면 "이제 내 에코를 0명부터 쌓는다"고 알려줍니다. (봇 기준: 에코 10명과 함께 학교 클리어 10/10, 에코 없이 0/5) 이전부터 플레이하던 저장은 튜토리얼을 마친 것으로 처리합니다.
- **일시정지**: 게임 중 ⏸ 버튼 또는 Esc/P. 앱을 내리거나 다른 창으로 가면 자동으로 멈춥니다. "그만하고 메뉴로"는 한 번 더 눌러야 하고, 그만둔 판은 기록되지 않습니다.
- **백업 코드에 에코 포함 (`ECHO2:`)**: 진행 데이터 + 에코 풀(월드, 최대 10명). 에코 경로는 4틱마다 한 점을 0.5px 단위 1바이트 차이로 저장하고 불러올 때 사이를 채웁니다(평균 오차 1px 미만, 에코 1명 약 7KB). 예전 `ECHO1:` 코드도 그대로 불러올 수 있습니다(이 경우 지금 에코는 유지).

## 디자인 원칙: 재미와 올바른 가치를 함께

이 게임은 학교·학원·회사·지하철 생활을 다룹니다. 재미를 위해 "적"이 필요하지만, 아래 원칙을 지킵니다. (원칙은 `test/worlds.test.js`의 자동 검사로도 지켜집니다)

1. **사람은 적이 아니다.** 선생님·선배·역무원·승객 등 사람은 적(중간 보스 포함)으로 등장하지 않습니다.
2. **숙제·시험·업무는 나쁜 것이 아니다.** 배움과 성장의 일부이므로 적으로 만들지 않습니다. 괴롭히는 것은 "숙제"가 아니라 **미루는 마음**, "시험"이 아니라 **시험 불안**입니다.
3. **적은 마음속·환경의 방해 요소**입니다: 미루기, 걱정, 졸음, 산만함, 피로, 스마트폰 알림 …
4. **보스는 "이기는" 대상이 아니라 "극복"하는 도전**입니다: 시험 불안, 슬럼프, 번아웃, 급행열차.
5. **도움을 청하는 것은 좋은 일**입니다. 선생님·선배·역무원이 도우미로 찾아오고, 곁에 가서 잠시 머물며 도움을 청하면 **조언 카드**(체력 회복 / 공격력 / 발사 속도 / 에코 응원)를 받습니다. 위험 속에서 도우미에게 가는 것이 이 게임의 재미 중 하나입니다.
6. **실패해도 괜찮다**는 메시지: 결과 화면에서 따뜻한 한마디를 보여주고, 쓰러진 나는 "에코"가 되어 다음 판을 돕습니다.
7. 도전 과제·일일 미션에도 "도움 요청하기"를 넣었습니다.

### 큰 도전(보스) 여러 번 + "에코가 있어야 겨우 깬다"

- **월드가 높을수록 큰 도전(보스)이 더 자주 등장**: 학교 1번 · 학원 2번 · 회사 3번 · 지하철 4번. 하나를 극복해야 다음이 나오고, 극복할 때마다 체력이 조금(25%) 회복됩니다. 뒤에 나올수록 더 단단하고 빠릅니다. 모두 극복해야 클리어.
- **에코가 없으면 사실상 못 깹니다.** 보스 체력은 `(나 + 에코 N명)의 기준 화력 x 목표 시간`으로 정해지고 **에코의 화력은 체력에 반영되지 않습니다.** 그래서 에코가 N명보다 적으면 전투가 몇 배로 길어져 못 버티고, N명이 있으면 겨우, 더 있으면 여유 있게 잡습니다. 필요 에코 수(`boss.needEchoes`): **학교 7 · 학원 8 · 회사 9 · 지하철 9명**. 월드 화면에 "권장 에코 N명+"가 표시되고, 부족하면 시작할 때/결과에서 알려줍니다.
- 내 화력이 기준보다 세면 보스는 그 √배만 단단해집니다(절반만 반영). 상점 강화만으로 보스가 시시해지지 않습니다.
- **보스전이 길어질수록 치명적**: 32초가 넘으면 보스가 격앙(이동 +25%)되고 받는 피해가 초당 +15%씩 늘어납니다(최대 6배). 보스전 중에는 받는 피해가 +25%(최대 체력이 높을수록 추가), 체력 재생은 40%.
- **체력 계열을 약하게**: 기본 체력 110, 상점 체력 +7/레벨, 급식 시간 +1.0/초, 체력 회복 카드는 절반, 보스 후 회복 25%, 커피 +12, 받는 피해 x0.9.
- **열차는 치명적**: 치이면 최대 체력의 40%(최소 40)가 깎입니다. 보스전 배율과 무관한 고정 피해, 한 대에 한 번.
- 튜닝 값은 `src/sim.js`의 `TUNING`(boss*, rage*, ref*)과 `src/worlds.js`의 `boss.times / needEchoes / fightSec / refMul`.
- 측정(봇, 상점 강화를 받은 플레이어, 판을 거듭하며 에코를 쌓음): **학교** 에코 0~3명 → 클리어 0/10, 5명 3/10, 6~7명 6~7/10, 10명 8/10. **학원** 8명 미만 0, 8명 2/5, 10명 5/5. **회사** 9명 미만 0, 9명 1/5, 10명 3/5. **지하철**은 봇이 보스 4번을 버티지 못해 검증하지 못했습니다(실제 플레이로 조정 필요).
