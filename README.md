# 퇴근 에코

자동공격 서바이벌 + **에코(과거의 나)** 모바일 게임. 한 판(120초)이 끝나면 그 판의 내 이동·강화 기록이 유령(에코)이 되어 다음 판에서 함께 싸웁니다.

목표: 모바일 앱 출시 / 수익화 / AI 활용 아트.

## 실행

```bash
npm run serve   # http://localhost:8080 (폰에서는 같은 네트워크의 PC IP로 접속)
npm test        # 시뮬레이션 테스트
```

## 구조

| 파일 | 역할 |
|---|---|
| `src/sim.js` | 결정론적 시뮬레이션 코어 (DOM 없음, 60Hz 고정 틱, 시드 난수). **밸런스는 `TUNING`, `WAVES`, `SWARMS`, `UPGRADES`, `ENEMY_TYPES`에서 조정** |
| `src/audio.js` | WebAudio 합성 효과음 (외부 에셋 없음) |
| `src/main.js` | 입력 / 렌더 / localStorage 저장 / 연출(흔들림, 데미지 숫자, 배너) |
| `test/sim.test.js` | 결정론, 에코 재생, 보스 페이즈, 업그레이드 등 12개 테스트 |

## 로드맵

- [x] **0단계** 프로토타입 (학교 월드, 에코 기본 루프)
- [x] **1단계** 핵심 루프 확장 — 아래 참고
- [ ] 2단계 메타 진행 (재화, 영구 강화, 캐릭터, 도전 과제, 저장 서버)
- [ ] 3단계 월드 확장 (학원/회사/지하철 …)
- [ ] 4단계 출시 준비 (AI 아트 교체, Capacitor 앱 패키징, 수익화 SDK, 베타)
- [ ] 5단계 출시 후 운영

### 1단계 변경점

- **적 8종 + 웨이브 표**: 숙제·쪽지시험·학원알림에 지각(돌진)·분필(원거리)·조별과제(분열)·담임(미니보스)을 추가. 시간대별 가중치 웨이브와 포위 이벤트(30/62/100초).
- **업그레이드 12종 (최대 Lv5) + 시너지 4종**: 치명타·종소리(충격파)·형광펜(공전)·급식(재생)·에코 응원·보건실(즉시 회복) 추가. 조합 시 시너지 발동.
- **에코 규칙**: 에코도 체력(30)이 있어 적에게 맞으면 사라짐 / 오래된 에코일수록 공격력 -5%씩 / 에코가 많을수록 적·보스 체력 증가 / 정원(20명) 초과 시 가장 일찍 쓰러진 에코부터 퇴장(오래 버틴 에코만 남음)(난이도 연동) / 에코 응원 업그레이드로 강화.
- **보스 "기말고사" 3페이즈**: 탄막 → 졸개 소환 → 조준 3연발 + 가속. 90초 등장, 120초까지 못 잡으면 최대 60초 연장전(보스전 중 졸개 스폰 절반).
- **연출·사운드**: 합성 효과음 12종, 화면 흔들림, 진동, 데미지 숫자(치명타 강조), 배너, 음소거 버튼.

> 밸런스 수치는 봇 시뮬레이션으로만 확인했습니다. 실제 사람 플레이테스트로 `TUNING` 값을 다듬어야 합니다.
